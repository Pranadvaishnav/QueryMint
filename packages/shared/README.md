# `@querymint/shared`

Shared chain definitions, token constants, EIP-712 manifest types, and hashing helpers used by QueryMint applications and the buyer SDK.

This package is distributed as ESM JavaScript with TypeScript declarations. It contains only public protocol definitions and constants; it has no coordinator keys, encryption keys, or private configuration.

After publication, install it with:

```sh
npm install @querymint/shared
```
